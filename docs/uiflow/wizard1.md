Screen Overview: AI Companion Selection Screen

The Selection Screen serves as the primary discovery hub for users to browse and select their preferred AI character. Designed with a modern, visual-first grid layout, it balances quick visual appeal with intuitive navigation to drive engagement.

Layout & Key Components

Header Section: Clean, dynamic top bar displaying the screen title ("Choose Your AI Companion"), a search/filter icon, and a subtle user profile avatar.

3x3 Character Grid: A responsive grid displaying 9 unique character tiles. Each tile presents:

High-Resolution Portrait: A distinct visual avatar for each AI character.

Name & Core Trait Title: Concise, personality-focused titles directly below or overlaid on the image (e.g., "Maya – The Creative Strategist" or "Elena – The Adventurous Traveler").

Status Indicator: Small visual badge (e.g., "Online", "New", or "Trending") to draw interest.

Card Interaction: Smooth hover/press states giving tactile visual feedback to signal interactivity.

Navigation & Transition: Character Profile Screen

Tapping any of the 9 character tiles seamlessly navigates the user to a dedicated Detailed Profile Screen:

Image Carousel / Gallery: A swipeable multi-image preview showcasing 3–5 additional contextual photos (lifestyle shots, action poses, or varied expression angles).

Extended Biography & Personality Overview: A rich description covering the character's background, conversational style, key interests, and sample voice preview button.

Call-to-Action (CTA): Prominent primary button ("Start Conversation") pinned to the bottom of the screen for immediate chat entry.
